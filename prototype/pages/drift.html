🔍 How the drift engine thinks (plain English)

1. Learn the normal.
ARGUS records what files an agent reads, which APIs it calls, how often, and how sensitive the data is. That becomes its behavioural baseline — its identity fingerprint.
2. Measure the deviation.
Every action is compared to the baseline using statistics (z-scores) plus a trend line. One odd action = noise. A consistent upward slope in sensitivity = a pattern.
3. Catch the slow crawl.
Classic exfiltration starts tiny: one extra file, then a folder, then an export. ARGUS detects the slope before the final export ever runs.
